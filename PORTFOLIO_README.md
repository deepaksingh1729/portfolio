A modern, high-performance **3D interactive developer portfolio** showcasing AI/ML systems, Computer Vision applications, and statistical modeling. Built with **Three.js WebGL**, **Tailwind CSS**, and zero build-step dependencies for instant deployment across GitHub Pages, Vercel, and Netlify.

---

## 🌟 Highlights & Key Features

- **🌐 Interactive 3D WebGL Neural Mesh**: Interactive 3D particle constellation and rotating AI polyhedron rendered using Three.js with real-time mouse parallax.
- **🎴 3D Tilt Cards**: Dynamic card perspective tilt with specular lighting glare on hover.
- **🧪 Interactive In-Browser AI Lab**:
  - **Legal Assistant (NLP/GenAI)**: Semantic query parsing and statutory citation extraction simulator.
  - **Clinical Trial RCT Analyzer**: Interactive sample size ($N$), Control vs Treatment efficacy slider with live Welch's $t$-test / $p$-value computation.
  - **House Price Regression Estimator**: Real-time multi-variable valuation calculator based on square footage, BHK, and location tier.
- **⚡ Spotlight Command Palette (`Ctrl+K` / `⌘K`)**: Quick keyboard navigation to jump straight to projects, demos, or contact actions.
- **📄 Print & PDF Optimized**: Dedicated print stylesheets (`@media print`) for clean 1-click recruiter PDF generation.
- **📱 Fully Responsive**: Pixel-perfect performance across mobile, tablet, and ultra-wide screens.

## 🚀 Quick Start & Deployment

### 1. Run Locally
Simply open `index.html` in any web browser:
```bash
# Optional: run with local server
npx serve .
```

### 2. Deploy Free on GitHub Pages (1 Minute)
1. Fork or push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`!
